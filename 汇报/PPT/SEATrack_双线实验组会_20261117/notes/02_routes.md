先看原模型。这页按照 SEATrack 原论文图二和方法第三节重新画了简化结构，保留了论文中两条模态路径、共享编码器、层内交互和末端融合的关系。RGB 与 X 模态各自都有模板和搜索图像，经过共享权重的 patch embedding，分别拼接为本模态的 token 序列，送入堆叠的共享 ViT 编码器。X 可以是红外、深度或事件模态，本次频域实验使用红外。

原模型每隔两层加入 AMG-LoRA 与 HMoE。增强编码器中共有四次子层残差更新：先归一化后计算注意力，再做 HMoE，然后归一化后经过 MLP，最后再做一次 HMoE；每一步都保留相应输入的残差连接。原模型的 patch embedding、基础 ViT 和预测头冻结，训练 K/V 的 LoRA、AMG 引导系数及 HMoE。AMG 的引导系数是训练得到的标量，并不是额外网络逐帧预测的可靠性权重。HMoE 先进行子 token 级软路由，经低秩专家再聚合为 token，分别对跨模态模板和跨模态搜索执行融合；代码中的两个 HMoE 分别使用四个和八个专家，参数独立。预测头输出中心分数图、尺寸图和偏移图。AMG-LoRA 一方面通过 K 和 V 的低秩适配进行域适应，另一方面在 softmax 之前对两路注意力 logits 做相互引导；HMoE 则负责跨模态的信息融合，其中模板和搜索分别组织跨模态 tokens。这里是各自的 self-attention 关系相互引导，不能画成 RGB 的 Q 直接与 X 的 K 做 cross-attention。

编码器最后只取两路 search 特征，原方法逐元素相加以后送进预测头输出目标框。后面两个改动的位置就很清楚了：SS 从选定 block 入口取特征，增加训练辅助损失，不替换原有 AMG 或 HMoE；频段融合则保留编码器内部交互，替换最末端的相加。两者作用位置不同，现阶段分别验证。

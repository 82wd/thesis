这页上方是原主干前向，下方虚线引出新增的训练辅助支路。入口特征仍然继续送入原编码器，SS 不在一次前向中先更新参数再生成修正特征。SS 的实际实现是完整的 patch 两两关系对齐，不是把 RGB 和辅助模态的特征逐元素拉近，也不是最初讨论的平均池化或 query anchor。首先把模板和搜索特征分开，每个 patch 沿通道维做归一化，然后在每个模态内部计算所有位置之间的余弦相似度矩阵。最后对两种模态各自的矩阵做 MSE，沿 batch 和两个空间维取均值。默认每路输入是 batch 乘三百二十乘七百六十八，归一化 epsilon 为十的负六次方。矩阵包含对角线和上下三角。

默认模板有六十四个 token，因此模板矩阵是六十四乘六十四；搜索有二百五十六个 token，搜索矩阵是二百五十六乘二百五十六。这里保留完整矩阵，不包含模板与搜索之间的交叉 pair。初版每层用零点五倍模板损失加零点五倍搜索损失，选中层取平均，再乘零点一加入原跟踪损失。

选中的位置是从零开始计数的 block 输入索引三、五、七、九、十一，也就是第四、第六、第八、第十、第十二个 block 之前。SS 运算采用 FP32，不 detach 特征，所以梯度能影响上游已有的 PEFT 参数。SS 本身没有可学习参数，普通推理会跳过计算。它增加的是训练时关系矩阵的计算开销，而不是额外的推理模块。默认原跟踪损失由二倍 GIoU、五倍 L1 和一倍 focal 组成。search-only 消融将模板权重改为零，搜索项仍为零点五，因此附加系数保持零点〇五。当前实现要求 direct 布局、没有 CLS、候选保留率为一，才能保证空间位置的对应。这些细节来自 semantic_alignment 和 backbone 的接入实现。

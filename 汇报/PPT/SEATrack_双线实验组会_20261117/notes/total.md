# 01_cover

这次主要汇报 SEATrack 上两个方向的探索：一个是在特征表征层面加入空间自相似性约束，另一个是在融合位置尝试不同模态的频段组合。汇报重点是方法怎么实现、目前证据说明什么，以及 SS 效果不够稳定以后做了哪些补救。最后只讨论后续项目实验，不涉及开发或部署安排。

目前的总体判断是，两条路线都需要独立验证。不能因为自相似性损失下降，就认为跟踪性能一定提高；也不能因为某个失败帧被救回，就认为频段分工已经成立。本次材料依据截至二〇二六年十一月十七日的本地代码和实验记录整理，尚未完成的结果会明确标注。

# 02_routes

先看原模型。这页按照 SEATrack 原论文图二和方法第三节重新画了简化结构，保留了论文中两条模态路径、共享编码器、层内交互和末端融合的关系。RGB 与 X 模态各自都有模板和搜索图像，经过共享权重的 patch embedding，分别拼接为本模态的 token 序列，送入堆叠的共享 ViT 编码器。X 可以是红外、深度或事件模态，本次频域实验使用红外。

原模型每隔两层加入 AMG-LoRA 与 HMoE。增强编码器中共有四次子层残差更新：先归一化后计算注意力，再做 HMoE，然后归一化后经过 MLP，最后再做一次 HMoE；每一步都保留相应输入的残差连接。原模型的 patch embedding、基础 ViT 和预测头冻结，训练 K/V 的 LoRA、AMG 引导系数及 HMoE。AMG 的引导系数是训练得到的标量，并不是额外网络逐帧预测的可靠性权重。HMoE 先进行子 token 级软路由，经低秩专家再聚合为 token，分别对跨模态模板和跨模态搜索执行融合；代码中的两个 HMoE 分别使用四个和八个专家，参数独立。预测头输出中心分数图、尺寸图和偏移图。AMG-LoRA 一方面通过 K 和 V 的低秩适配进行域适应，另一方面在 softmax 之前对两路注意力 logits 做相互引导；HMoE 则负责跨模态的信息融合，其中模板和搜索分别组织跨模态 tokens。这里是各自的 self-attention 关系相互引导，不能画成 RGB 的 Q 直接与 X 的 K 做 cross-attention。

编码器最后只取两路 search 特征，原方法逐元素相加以后送进预测头输出目标框。后面两个改动的位置就很清楚了：SS 从选定 block 入口取特征，增加训练辅助损失，不替换原有 AMG 或 HMoE；频段融合则保留编码器内部交互，替换最末端的相加。两者作用位置不同，现阶段分别验证。

# 03_ss

这页上方是原主干前向，下方虚线引出新增的训练辅助支路。入口特征仍然继续送入原编码器，SS 不在一次前向中先更新参数再生成修正特征。SS 的实际实现是完整的 patch 两两关系对齐，不是把 RGB 和辅助模态的特征逐元素拉近，也不是最初讨论的平均池化或 query anchor。首先把模板和搜索特征分开，每个 patch 沿通道维做归一化，然后在每个模态内部计算所有位置之间的余弦相似度矩阵。最后对两种模态各自的矩阵做 MSE，沿 batch 和两个空间维取均值。默认每路输入是 batch 乘三百二十乘七百六十八，归一化 epsilon 为十的负六次方。矩阵包含对角线和上下三角。

默认模板有六十四个 token，因此模板矩阵是六十四乘六十四；搜索有二百五十六个 token，搜索矩阵是二百五十六乘二百五十六。这里保留完整矩阵，不包含模板与搜索之间的交叉 pair。初版每层用零点五倍模板损失加零点五倍搜索损失，选中层取平均，再乘零点一加入原跟踪损失。

选中的位置是从零开始计数的 block 输入索引三、五、七、九、十一，也就是第四、第六、第八、第十、第十二个 block 之前。SS 运算采用 FP32，不 detach 特征，所以梯度能影响上游已有的 PEFT 参数。SS 本身没有可学习参数，普通推理会跳过计算。它增加的是训练时关系矩阵的计算开销，而不是额外的推理模块。默认原跟踪损失由二倍 GIoU、五倍 L1 和一倍 focal 组成。search-only 消融将模板权重改为零，搜索项仍为零点五，因此附加系数保持零点〇五。当前实现要求 direct 布局、没有 CLS、候选保留率为一，才能保证空间位置的对应。这些细节来自 semantic_alignment 和 backbone 的接入实现。

# 04_frequency

这页把原图末端的相加拆成一条显式的频域路径，编码器中的 AMG-LoRA 和 HMoE 继续保留。频段融合是在末层已经归一化、恢复空间顺序的 search tokens 上进行，模板不直接参与。把每路特征恢复为通道乘高乘宽的空间网格，再逐通道计算二维实数 FFT。默认 search 输入是 batch 乘二百五十六乘七百六十八，恢复为 batch 乘七百六十八乘十六乘十六；实数 FFT 的半谱形状是 batch 乘七百六十八乘十六乘九。空间网格由搜索尺寸和 patch stride 推导，模块没有写死十六乘十六。根据径向频率，把不超过零点二五周期每格的部分定义为低频，其余定义为高频。组合时保留完整复数系数，因此幅值和相位都参与；之后逆变换并乘 gain，恢复原数据类型，继续使用原预测头、Hann 窗和框解码。

图中的中心圆表示低频区域，外部表示高频区域，彩色部分是本路保留的频段。这只是便于理解的中心化频谱示意，不是真实谱图，也不是实际 rFFT 半谱数组的布局。

目前比较两种固定分工：RGB 低频加红外高频，以及红外低频加 RGB 高频。两路末层特征此前已经经过跨模态交互，所以这里的 RGB 和红外指网络分支，不能直接解释成完全独立的原始模态信息。

用公式表示，就是两路复数频谱 A 和 B 按 w 和一减 w 加权，再做逆变换并乘 gain。w 在低频和高频分别取不同值。RGB 低频加红外高频对应一和零，反向对应零和一。

控制组也很重要。低高频都用零点五的 RGB 权重、gain 等于二时，代码直接返回两路相加，保证与原融合的逐元素一致性。当前模块没有可学习参数，但 FFT 不会阻断梯度，训练时仍可优化原网络允许训练的参数。gain 等于二只是沿用相加的系数约定，并不保证硬频段选择后的 RMS 与原相加相同。幅值影响必须单独分析。这里讲的是当前特征层固定频段模块，与历史决策图融合尝试区分。

# 05_ss_ablation

想法三对应十一月十二日针对 SS 不起作用提出的小步验证。这里的 query image 指搜索图像，不是新增可学习 query token。首先将模板 SS 权重设为零，仅约束搜索区域的跨模态空间自相似性；模板仍参与原编码器前向。搜索损失保留原来的零点五权重，乘总系数零点一后是零点零五，不因删除模板项而翻倍。

第二步是选择施加约束的层。图中展示零基索引三、五、七、九、十一的入口，箭头表示网络深度，中间层省略。多层实验取五处搜索损失的平均值；单层消融则每次只启用一处，单独训练和评测，不能把不同层的收益混在一起。同步记录逐层训练与验证 SS 曲线，检查收敛动态，同时用跟踪指标判断效果。SS 下降并不自动意味着跟踪更准确。

先把验证范围缩到 LasHeR，并控制初始化、数据采样和更新次数。结合半权重对照区分约束区域和总强度的影响。这里展示的是消融设计和现有损失接口，最终 search-only 与单层结果仍待核验；已经完成的 template-only 与 target-aware 调整在后续结果页汇报。

# 06_evidence

现在看证据。首先是初版 SS 的全量评测。LasHeR 的 SR 从百分之五十七点五一降到五十六点七一，下降约零点八个百分点；RGBT234 的 MSR 则从百分之六十三点七三提高到六十四点六七，提高约零点九四个百分点。因此不能说 SS 完全无效，但也不能说它带来了全面稳定的收益。

右边是十一月十二日的历史固定搜索区域回放，不是当前频段模块的全量评测。实验覆盖八段片段、八十八个帧位置、八百八十次预测。在第一版 SS 权重上，红外低频加 RGB 高频让白车失败帧的 IoU 从零提高到零点八一一，匹配 RMS 后为零点八二五。但人脸失败帧仍没有找回，而且六段稳定对照共六十六帧的平均 IoU 从零点八〇二降到了零点七七一。

这说明某些局部帧确实可能受益，但固定模态频段分工还没有被支持。固定搜索区域试验不能推出闭环恢复能力，更不能代替全量跟踪指标。下一步需要把对照做完整，而不是仅保留改善的案例。数据来源为实验日志与 RGB-T 频段互换观察记录。

# 07_remedies

针对 SS 效果不佳，已经做了两种区域调整。A 是 template-only，只保留模板区域的 SS，移除搜索区域的直接约束，用来检查搜索项是否引入了不利影响。B 是 target-aware，保留模板项，对搜索区域使用训练目标框计算 patch 的目标覆盖率，把约束放在前景与前景、以及双向前景与背景的关系上。各组在样本内按质量归一，再对有效组取平均，避免把所有背景关系不加区分地混在一起。

两组都完成了六十轮训练及评测。LasHeR 的 SR，A 为百分之五十七点三一，B 为五十七点二九，都比初版的五十六点七一有所恢复，但仍低于未加 SS 基线的五十七点五一。在 RGBT234 上，A 和 B 的 MSR 分别为百分之六十四点〇三和六十四点〇六，又低于初版 SS 的六十四点六七。因此准确的表述是部分恢复，并没有证明普遍改善，也还不能据此确定背景关系就是退化原因。

接下来按师兄建议，把验证范围缩到 LasHeR，先测试只对 search 施加约束的多层方案，再逐个测试第三、五、七、九、十一这些零基索引位置。search-only 保留原搜索项系数，所以最终附加项是零点〇五乘所选层搜索 MSE 的平均值，并非去掉模板以后把搜索项翻倍。同步记录逐层训练和验证曲线，还要结合最终跟踪指标判断。最终 search-only 结果和半权重对照仍待核验，不能预先写成有效。

# 08_next

后续实验围绕两个具体问题展开。SS 这边，要区分约束区域、约束层和约束强度的影响。先比较 search-only 多层与原版，再做单层实验定位作用位置，同时补齐半权重对照，判断 template-only 的变化究竟来自移除搜索项，还是仅仅来自整体约束减弱。观察曲线是为了理解收敛过程，不替代性能评估。

频域这边，先在同一份确认未经过 SS 训练的权重上，对比原始相加和等权融合，验证完整轨迹的一致性；再比较两种固定频段互换，并检查幅值敏感性。历史局部回放与当前模块实验需要分开报告，最终采用统一协议做全量评测。

所有比较都要先核对初始化、随机种子、数据、有效 batch、采样量和优化器更新次数。尤其历史实验与当前配置存在训练预算差异，不能自动当作公平消融。配置选择用验证集，最后再统一评测测试集。本阶段目标是先在 LasHeR 上获得稳定、可解释的证据，再决定是否扩展 benchmark 或组合两个模块。

# Search-only SS 优化动态

数据：单次 seed 0 训练，60 个完整训练 epoch 与 12 个验证 epoch（5、10、…、60）。取每轮最后一条 1875/1875 日志中的累计样本平均值，不对日志中的中间累计均值再求平均。没有插值补造观测、平滑或排除 epoch；线段仅连接观测点。日志保留五位小数，派生比值和差值有舍入误差。

## 如何看图

01 是未加权的搜索 SS；02 是总损失减去日志中加权 SS 得到的跟踪损失；03 是训练/验证采样裁剪图上的 IoU，不是完整跟踪测试 SR；04 是加权 SS / 总损失的百分数，不是梯度贡献；05、06 展示进入第 4、6、8、10、12 层之前的搜索 SS，分别为训练和验证。07—09 是尚未乘各自系数的跟踪损失分量；10 是加权 SS。

五层原始搜索 SS 平均后乘 0.05 才进入总损失。模板 SS 全部为零是未计算，故不画作收敛曲线；源 CSV 仍保留全部模板字段。10 张均为独立单面板图，因此多面板对齐检查不适用。采用英文图内标签避免中文字体替换，中文解释在本文件中。

## 目前可以说的结论

训练 search SS 从第 1 轮 0.02681 降至第 60 轮 0.01990，下降约 25.8%；验证 search SS 从第 5 轮 0.02342 降至第 60 轮 0.01827，下降约 22.0%。两者起始轮次不同，不直接比较降幅优劣。

训练 IoU 从 0.69598 升至 0.76448，验证 IoU 从第 5 轮 0.74016 到末轮 0.74854。验证 IoU 的记录最高值在第 50 轮，为 0.75055；验证 SS 的记录最小值在第 55 轮。因此 SS 降低与验证 IoU 改善并不严格同步，不能声称后期每次关系对齐都带来性能提升。

末轮加权 SS 约占总损失的 0.095%（训练）和 0.080%（验证），前者按五位小数日志 0.00099 计算；按原搜索 SS 乘 0.05 重算约为 0.096%。这是数值尺度，不是梯度尺度。

## 不能由这些图得出的结论

只有一条 search-only 运行，没有同预算无 SS 基线曲线，没有多种子误差条，没有梯度范数或梯度夹角记录。不能据此证明 SS 优于基线、确定过拟合原因或判断梯度冲突。训练/验证的裁剪、增强和采样条件不同，验证损失低于训练损失本身不是异常证据。

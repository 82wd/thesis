# 第20轮可视化结果

双击 index.html 打开中文离线展示；请保留整个目录，网页依赖同目录图片与视频。

- 旧基线 vs SS：均为第20轮，3序列共750帧，连续跟踪，不逐帧重置。
- 绿色GT，蓝色基线，红色SS；热红外画面仅为场景参考。
- 3个浏览器兼容H.264视频、18张关键帧、3张拼图、60张SS热力图。
- 所有序列和展示帧事先固定。SS热力图用相同GT中心裁剪，与连续跟踪输入分开。
- 58/60组配对诊断的SS差异更小，不等于跟踪效果提升，不是60个独立样本。
- manifest.json：权重SHA与设置；sha256.json：服务器原始输出校验和；verification.json：服务端检查结果；browser_video_verification.json：本地H.264视频解码帧数。
- 原始视频保留tracking.mp4，网页用tracking_browser.mp4，二者帧数一致；20FPS仅为回放速度。
- 全部原始109文件SHA本地核验通过。图片可直接插入PPT。
